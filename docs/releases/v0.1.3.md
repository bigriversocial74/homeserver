# Microgifter HomeServer v0.1.3

HomeServer v0.1.3 is the production-hardening release for the Windows edge platform. It preserves the existing Control Center, LocalSystem service, local SQLite data, cloud pairing and synchronization, encrypted backup and recovery, and signed-update foundation while closing the material security, installer, rollback, and release-engineering gaps identified in the full repository audit.

## Highlights

- Machine-scoped Windows DPAPI protection for cloud credentials and device backup keys.
- Explicit ProgramData access limited to LocalSystem and local administrators.
- Complete loopback API browser-origin rejection and trusted native-client enforcement.
- Bounded cloud responses, queues, retries, receipts, release notes, logs, recovery archives, and update downloads.
- Safer interrupted file replacement, recovery import, update staging, and rollback handling.
- Clean native service and updater builds with synchronized version reporting.
- Full workspace tests, strict Clippy, npm audit, RustSec audit, and security-boundary regression checks.
- Installed NSIS verification covering LocalSystem registration, ACLs, credential vault access, backup integrity, uninstall behavior, and retained-data preservation.
- Authenticode verification, signed update application, health confirmation, automatic rollback, and installer preservation.
- Tag-gated production release workflow with production certificate validation, Ed25519 manifest signing, SHA-256 checksums, and GitHub Release publication.

## Release artifacts

A published v0.1.3 release contains:

- `Microgifter-HomeServer-v0.1.3-Setup.exe` — customer-facing versioned installer.
- `Microgifter-HomeServer-Setup.exe` — stable update-channel installer.
- `homeserver-stable.json` — Ed25519-signed stable update manifest.
- `SHA256SUMS.txt` — SHA-256 checksums for all published release files.
- `release-notes.md` — release notes embedded into the signed update manifest.

## Supported platform

- Windows 11 x64 is the supported initial production platform.
- Installation is per-machine and registers the HomeServer background service as LocalSystem.
- The local service binds only to `127.0.0.1:47831`.

## Upgrade and recovery

The installer preserves managed HomeServer data during an upgrade. Before applying an update, HomeServer creates and verifies a pre-update backup. A failed post-update health check triggers automatic rollback to the previous installer and preserved database state.

Portable recovery packages remain passphrase-encrypted and can be imported after reinstalling HomeServer or moving to another Windows installation.

## Security note

Only installers carrying the production Authenticode certificate identified by the signed update manifest are accepted by the updater. The update manifest is independently signed with the HomeServer release Ed25519 key. Release publication fails if the configured private key, public key, certificate thumbprint, version tag, or generated installer does not match the expected production contract.
